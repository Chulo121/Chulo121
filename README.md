### 🛍️ 关于我

- 🧮 专注 **电商行业数据分析**：销售趋势分析、用户画像与聚类、营销 / 广告投放效果评估、评论情感分析、预测建模
- 🎯 目标是把零散的电商交易数据，转化为可以指导运营决策的洞察
- 🌱 持续在打磨 Python 数据分析与机器学习的工程化能力
- 📌 目前主推的仓库 👉 **[ecommerce-data-analysis](https://github.com/Chulo121/ecommerce-data-analysis)** —— 9 个电商数据分析实战项目合集

<br/>

### 📂 电商分析项目地图

| 方向 | 对应项目 | 关键方法 |
|---|---|---|
| 🛒 销售 / 市场分析 | 超市销售数据分析、天猫双十一美妆分析、母婴市场消费分析 | 数据透视、Pandas、Matplotlib / Pyecharts |
| 👥 用户分群 | 优衣库门店 & 顾客分组、广告投放效果分析 | KMeans 聚类、地图可视化 |
| 💬 文本 / 情感分析 | 京东评论情感分析 | 中文分词、关键词提取、词云 |
| 🤖 预测建模 | 天猫优惠券使用预测、小红书消费金额预测 | 逻辑回归、线性回归、模型评估优化 |
