探索电商与 AI 的应用 · Exploring the use of e-commerce and AI

### 🛍️ 关于我

🎓 小白一枚，关注 AI Agent、数据分析与数字商业 的交叉应用。

🔍 对电商行业有浓厚兴趣，注重从数据中提炼洞察，并将分析结果转化为实际业务价值。

💻 持续探索 AI Agent、工作流自动化与工具集成，关注大语言模型在信息获取、数据处理及业务流程优化中的应用。

📚 这里主要记录技术实践和一些之前练手的项目，欢迎交流。

📁过去学习项目： **[ecommerce-data-analysis](https://github.com/Chulo121/ecommerce-data-analysis)**

### 📂 电商分析项目地图

| 方向 | 对应项目 | 关键方法 |
|---|---|---|
| 🛒 销售 / 市场分析 | 超市销售数据分析、天猫双十一美妆分析、母婴市场消费分析 | 数据透视、Pandas、Matplotlib / Pyecharts |
| 👥 用户分群 | 优衣库门店 & 顾客分组、广告投放效果分析 | KMeans 聚类、地图可视化 |
| 💬 文本 / 情感分析 | 京东评论情感分析 | 中文分词、关键词提取、词云 |
| 🤖 预测建模 | 天猫优惠券使用预测、小红书消费金额预测 | 逻辑回归、线性回归、模型评估优化 |
